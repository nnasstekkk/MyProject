\# Архитектура проекта



\## Структура

\- `src/main.py` — основной модуль программы.

\- `docs/` — документация.

\- `tests/` — тесты.



\## Алгоритм работы

1\. Пользователь вводит размеры матрицы (n, m).

2\. Программа считывает элементы построчно.

3\. Выводит элементы по столбцам.



\## Технологии

\- Python 3.8+

\- Git для контроля версий

\- GitHub Actions для CI/CD
