\# План тестирования



\## Виды тестирования

\- Ручное тестирование ввода/вывода.

\- Автоматическая проверка кода через flake8 (в CI).



\## Тестовые сценарии

1\. Ввод матрицы 2x2 — проверка корректного вывода по столбцам.

2\. Ввод матрицы 3x3 — проверка корректного вывода.

3\. Ввод дробных чисел — проверка типа float.

4\. Некорректный ввод — программа должна выдать ошибку.
