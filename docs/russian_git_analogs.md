\# Обзор российских аналогов Git



\## 1. GitFlic (№15861)

\- Российская DevOps-платформа.

\- Альтернатива GitLab.

\- Доступна в облачной и локальной версиях.



\## 2. GitFlame (№21590)

\- Сервис хранения репозиториев с версионным контролем.

\- Создан для разработчиков и DevOps-инженеров.



\## 3. Gitlife Enterprise (№29396)

\- Модульная платформа для управления жизненным циклом проектов.

\- Включает модуль «Код» на базе Git.



\## Вывод

Российские аналоги Git полностью покрывают базовые потребности в контроле версий и подходят для использования в организациях, работающих в условиях импортозамещения.
