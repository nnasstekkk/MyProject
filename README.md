# Проект: Обработка вещественных матриц

## Назначение
Программа для ввода вещественной матрицы построчно и вывода её по столбцам.

## Требования к окружению
- Python 3.8+

## Инструкция по запуску
1. Перейдите в папку `src`.
2. Запустите скрипт: `python main.py`
